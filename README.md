# Birthday Card Website 🎂

A creative, interactive birthday-card website built with **HTML, CSS, and JavaScript**.

## Features
- Responsive layout for desktop and mobile
- 3D-style cake illustration made with CSS
- Personalize the greeting with any name
- Interactive envelope that opens a birthday letter
- Make-a-wish button with random birthday wishes
- Three photo-memory cards that let you preview images from your device
- Confetti celebration effects

## Run locally
1. Download or extract this project folder.
2. Open `index.html` in your browser.
3. Type a name and click **Personalize**.
4. Open the envelope and add photos to the memory cards.

No build tools or dependencies are required. The Google Fonts connection needs internet access; the page still works without it using fallback fonts.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site and open the URL it provides.

## Customize
Edit the text in `index.html` to change the greeting and memory captions. The name is customizable directly on the page. Photo previews are local to the current browser session and are not uploaded or saved to a server.
